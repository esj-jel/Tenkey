# Kotoba v1.1.0 — Grammar + Widget foundations

- Split the project into separate Kotoba Grammar and Kotoba Widget Android apps.
- Added offline daily learning cards and a catalog of 111 language labels.
- Added starter card packs for Japanese, Cantonese, Korean, Simplified Chinese and Traditional Chinese.
- Added a transparent Android widget with a conditional keyguard category and a next-card tap.
- Added SwiftUI source for the Grammar app, Widget app and WidgetKit Lock Screen/Home Screen extension.
- Added the Kotoba SVG brand icon and updated project documentation.
- Removed network permission and network-dependent AI UI from the Android Grammar app.

## Scope and validation status

The catalog has 111 labels; complete lesson packs are not yet included for all 111. Unsupported lessons currently fall back to Japanese. Android build/test validation is performed in the Linux repository environment. iOS archives require a Mac with Xcode and signing. Physical device/emulator testing was unavailable.
