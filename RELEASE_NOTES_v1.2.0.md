# Kotoba 1.2.0 — Widget lessons and local builds

- Kept **Kotoba Grammar** and **Kotoba Widget** as distinct Android and iOS app targets.
- Expanded the Android widget language selector to all 111 catalog labels; 12 curated lesson packs are included and the other 99 languages clearly fall back to Japanese starter lessons.
- Added character/word labels, translations, explanations, and language-appropriate romanized readings to Android widget cards.
- Added additional Japanese kanji/radical cards before word cards.
- Expanded iOS Kotoba Widget language selection to the full 111-label catalog and added explanations to larger widget families.
- Updated Android package version to 1.2.0 and retained Android API 36 support.
- Documented OS-controlled widget refresh behavior, offline-content coverage, and local Android/macOS build steps.
- iOS `.ipa` distribution still requires macOS/Xcode and Apple signing/provisioning; MagicOS/iOS 27 compatibility remains unverified on devices in this workspace.
