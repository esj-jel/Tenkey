# Tenkey v1.0.2

Tenkey now feels like a real customizable keyboard rather than a shell.

The keyboard surface has a Florisboard-inspired Material You treatment with gradient theming, rounded elevated keys, custom profiles, imported fonts, haptic feedback controls, and a long-press globe language shelf.

Users can hold the globe key to see their selected languages, switch directly between them, open language management, and still tap the globe for Android’s next-keyboard behavior. The Custom keyboard studio supports language tags, custom rows, local profiles, and an optional AI designer. Users enter their own API key; Tenkey encrypts it with Android Keystore and does not ship a key of its own.

A built-in tutorial covers typing, Hiragana/Katakana mode, language switching, cursor movement, utility panels, customization, and privacy. Settings also include user font import, haptic feedback, and key sound preferences.

Validation: unit tests passed, Android lint completed with zero errors, and the v1.0.2 debug APK assembled successfully.
